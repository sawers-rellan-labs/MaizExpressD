# CLAUDE.md — MaizExpressD

Working notes for Claude Code. The plan is in `HANDOFF.md`; read it first.

## Project
An R/Shiny dashboard for looking up maize genes and seeing where and when they are expressed across tissues and developmental stages in the 282 diversity panel, how that varies among lines, and how it links to eQTLs and agronomic traits. Owner: Rubén Rellán-Álvarez (GEMMA Lab, NC State).

Sibling of **MaizExpressN** (nitrogen, `/Users/rra/Documents/MaizExpressN`) and **MaizExpressC** (cold, `/Users/rra/Documents/MaizExpressC`); their CLAUDE.md files hold the history behind every inherited decision. Unlike them, D has one expression study (no pooling across studies) and no treatment: its contrasts are between tissues of the same line.

## Sources of truth
- Studies: `catalogue/studies.tsv` (Kremling2018 for expression, Lei2025 for the eQTL/TWAS/QTL results).
- Curated inputs: `metadata/build/tissues.tsv`, `metadata/build/line_aliases.tsv`. `metadata/runs.tsv`, `samples.tsv` and `lines.tsv` are generated by `metadata/build/build_metadata.py`; never edit them by hand.
- Open questions: `metadata/needs_review.tsv`.

## Conventions
- Primary gene key: B73 RefGen_v5 gene IDs (`Zm00001eb…`), as in N and C. Lei's tables use v3 IDs (`GRMZM…`); converted at M5 (`annotation/build_lei.R`, `annotation/lei_*`).
- Study key `Kremling2018`; tissue codes from the library names (`GRoot`, `GShoot`, `L3Base`, `L3Mid`, `L3Tip`, `LMAD`, `LMAN`, `Kern`), with Lei's codes (`RT`, `SH`, `LB`, `LT`, `LD`, `LN`, `KN`) alongside.
- Genotype key: the library-name spelling (merged across spellings of one line); `genotype_lei` links to Lei Table S1.
- Adult leaf was sampled in two groups (8 and 26 in the library names) that differ in germplasm; compare day with night within line and group, never by group alone.
- R for analysis and the app (renv, copied from MaizExpressC at M4). Heavy processing runs on Hazel (Slurm); only gene tables and Parquet results come back to the Mac.
- Python scripts that read downloaded data run with `python3 -I` from the project root.

## Rules inherited from MaizExpressN and C (apply here unless Rubén says otherwise)

- Public-facing files (app, public repo, Methods) never say why a library or line was left out; reasons and evidence go in `private/` (gitignored).
